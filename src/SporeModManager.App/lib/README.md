# ModAPI.DLLInjector.dll

`ModAPI.DLLInjector.dll` is taken from the official **Spore ModAPI Launcher Kit**
(v1.5.13, `ModAPI.InterimSetup.exe`), maintained by the Spore Community:

- https://github.com/Spore-Community/ModAPI-Launcher-Kit
- License: MIT

It is bundled so the manager can launch Spore with ModAPI without requiring a
separate Launcher Kit installation. If a different Launcher Kit is already
installed, the app still prefers the bundled copy unless one is found next to
the app or in a standard Launcher Kit location.
